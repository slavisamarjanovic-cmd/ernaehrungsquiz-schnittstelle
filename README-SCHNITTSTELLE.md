# Ernährungsquiz – Schnittstelle (privat)

Dieses private Repository enthält den **vollständigen** Projektstand inklusive
`apps-script/` mit Lösungsschlüssel und Begründungen. Die öffentliche Quizseite liegt
im Repository `ernaehrungsquiz` (ohne `apps-script/`).

Wirksam ist immer der Code im Apps-Script-Projekt der Google-Tabelle. Nach Änderungen an
`apps-script/*.gs` hier: Inhalt ins Apps Script kopieren → speichern →
Bereitstellen → Bereitstellungen verwalten → ✏ → Neue Version → Bereitstellen.
Änderungen an `assets/` zusätzlich im öffentlichen Repository nachführen.
